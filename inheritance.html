Inheritance

Inheritance in Java is an important feature of Object-Oriented Programming (OOP) that allows one class to acquire the properties and methods of another class. The class that provides the properties and methods is called the parent class (superclass), and the class that inherits them is called the child class (subclass). Inheritance helps to achieve code reusability, reduce code duplication, and make programs easier to maintain. Java supports inheritance using the `extends` keyword. The main types of inheritance are single, multilevel, and hierarchical inheritance. For example, a `Dog` class can inherit from an `Animal` class, allowing the `Dog` class to use the methods and properties of `Animal`.
